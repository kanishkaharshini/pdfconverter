# 📄 Image to PDF Converter

A simple web application that allows users to upload images and convert them into a single PDF file.

## 🚀 Features

- Upload multiple images
- Drag & drop support
- Preview selected images
- Convert images into a single PDF
- Clean and simple UI

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Libraries: Pillow, reportlab (or your used libs)

## 📂 Project Structure

```
image-to-pdf/
├── static/
│   ├── script.js
│   └── style.css
├── templates/
│   └── index.html
├── app.py
├── converter.py
├── requirements.txt
```

## ▶️ How to Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open browser:

```
http://127.0.0.1:5000
```
